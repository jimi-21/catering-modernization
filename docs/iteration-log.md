# 深度迭代记录

本轮以真实访客、内容管理员、异常输入和部署运维为视角，持续检查并修复问题。所有最终修改均在 Docker 生产容器中验收。

## 数据安全与迁移

- 种子和旧站迁移默认只创建缺失内容，不再覆盖后台已有编辑；只有显式 `--overwrite` 才允许覆盖。
- 数据库迁移改为事务执行，报告区分新建、保留和覆盖数量。
- 非法日期、正文长度不足、过长字段和重复旧 URL 会进入逐条报告，不再静默失败。
- slug 冲突自动追加旧 ID，并处理同 ID 多重冲突及 100 字符边界。
- 内容类型与 slug 创建后不可修改，前后端同时约束，避免误改公开 URL 造成 404。
- 撤下再发布保留首次发布时间，不再把旧文章伪造成最新内容。
- 管理员工邮箱统一小写并复用登录校验，避免大小写或弱密码配置导致无法登录。

## 上传与存储

- 上传文件经过二进制签名检查、Sharp 真实解码、像素限制、EXIF 旋转、尺寸限制和 WebP 重编码。
- 不再依赖浏览器提供不一致的 MIME，修复 WebKit 上传失败。
- 替换封面会清理旧文件，删除内容会清理关联文件，保存失败会回收新文件。
- 已验证 Web 容器重启后上传仍然存在，删除内容后对应文件返回 404。

## 认证、安全与隐私

- 后台鉴权重新查询用户和角色；账号删除或降级后，旧会话立即失效。会话 Cookie 仅在 HTTPS 下启用 Secure，兼容本地 HTTP 生产构建与 WebKit。
- 不存在账号也执行虚拟密码哈希，减少登录时间差；非管理员账号不能登录后台。
- 登录增加账号级与 IP 级限流，公开咨询增加 IP 限流，所有限流 Map 都有过期清理和最大容量。
- 修复蜜罐字段校验，机器人返回成功但不写入数据库。
- 咨询支持状态更新和确认删除；状态更新后界面与数据库保持一致。
- 增加匿名后台、篡改 Cookie、XSS 搜索、路径穿越和恶意表单测试。
- 公开咨询与服务端校验失败时保留用户输入，只有成功提交才清空。

## 跨浏览器与可访问性

- 修复 Safari 打开 Popover 时 ResizeObserver 误关闭菜单的问题；打开状态不再执行破坏性测量。
- 修复 React Server Action 自动重置导致的长表单内容丢失和咨询状态回显错误。
- 修复 Firefox 宽表格撑大 Grid 的问题，表格仅在自身容器滚动，并可键盘聚焦。
- Markdown 一级标题自动降级，保持页面只有一个 h1；原始 HTML 不执行。
- 覆盖 320px 窄屏、公共页面与后台横向溢出、空/有数据咨询列表及删除对话框的 axe 检查；reduced-motion 与 forced-colors 下仍无溢出且焦点可达。
- 无 JavaScript 时，原生移动菜单、咨询提交和管理员登录仍可用。

## SEO、性能与可维护性

- 列表和后台查询只选择展示所需字段，不再读取完整 Markdown 正文。
- 内容列表与咨询列表均有共享分页组件，旧记录不再不可达。
- 静态 sitemap 条目不再每次请求伪造 `lastModified`；内容条目保留真实更新时间。
- 站点 URL 去除尾斜杠，咨询方向使用前后端共享白名单；中文日期固定使用 Asia/Shanghai，咨询显示到分钟。
- 新增 1200×630 JPEG Open Graph 封面，提高社交平台兼容性。
- 增加 Web 健康检查，Caddy 仅在应用真正可响应后启动；HSTS 默认不扩展到子域名，避免影响甲方其他站点。
- GitHub Actions 增加 Firefox 与 WebKit 完整测试。
